# Amar Battleground

A small browser-playable battle-royale shooter prototype.

## Run
Open `index.html` in a modern browser.

## GitHub Pages
1. Create a GitHub repository named `Amar-Battleground`.
2. Upload `index.html` and this README.
3. Go to Settings -> Pages.
4. Deploy from the `main` branch, root folder.
5. Open the generated GitHub Pages URL.

## Controls
WASD = move
Mouse = aim
Left click = shoot
R = reload
Enter = restart after death/victory
